지금은 AI 사용이 허용된 개발 작업 단계다. 먼저 현재 과제 루트, 공식 안내, README와 적용 지침을 확인해줘.
Computer Use는 어떤 단계에서도 절대 사용하지 마. 브라우저·데스크톱 GUI를 도구로 조작하지 말고 파일·터미널·프로젝트 테스트로 작업해줘. 화면 조작과 GUI 확인은 내가 직접 할게.
.codex-playbook/AGENTS.md를 보조 규칙으로 읽고 PLAYBOOK.md는 필요한 단계만 참고해줘. 기존 과제 규칙이 우선이다.
AGENTS.md의 Developer Understanding Protocol에 따라 구현 전에는 1분 안에 이해할 수 있게, 주요 기능 완료와 제출물 확정 전에는 핵심만 브리핑해줘. 내가 "이해 점검"을 요청하면 질문 1개를 내고 내 답변을 받은 뒤 평가해줘.
대시보드·웹 UI 과제에서만 .codex-playbook/UI_ASSETS.md를 읽어줘. 기존 스택·UI를 먼저 확인하고 호환성·라이선스·통합 비용상 유리한 에셋만 재사용해줘. 필수 기능 구현 → 실제 실행 → 오류 수정 → UI 개선 → 최종 검증 순서로 진행해줘.
필수 요구사항·제출 파일·완료 기준을 짧게 정리하고, 기존 스택으로 입력부터 출력까지 이어지는 MVP를 실제 구현해줘.
정상·경계·예외 입력과 관련 회귀 검증을 실행하고 명령·관측 결과·미실행 이유를 기록해줘.
기술 선택 이유, AI 제안에서 수정한 부분, 검증 결과와 한계를 지정된 작업 문서에 작업 중 기록해줘. 파일명은 과제 안내를 따라줘.
웹 과제라면 제공된 Browser에서 확인할 수 있도록 기존 실행 명령의 바인딩·실제 포트·경로를 확인해줘.
작은 가역적 선택은 진행하고 중요한 판단과 장애만 짧게 보고해줘. 계획에 멈추지 말고 구현과 검증까지 이어가줘.
실제 시험 환경에서는 Codex 업데이트, 개인 API 키·구독 사용, 불필요한 설치·MCP 구축, 운영 설정 변경·제한 우회, 외부 전송과 Git Push를 하지 마.
후속 서술형은 AI 금지 단계다. 작업 기록은 제출물 확정 전에 정리하고, 서술형 답안 생성·수정은 돕지 마.
